# Smaragdify — product & gallery images

Drop your photos into this folder. The page picks them up automatically by filename.
Until a file exists, an elegant emerald-green placeholder shows in its slot.

## Expected filenames (rename your photos to match, or edit the paths in index.html)

**Hero & story**
- `hero.jpg`   — main hero shot (a ring/earring close-up works best) — landscape
- `story.jpg`  — a raw emerald / mine / crafting shot — portrait (4:5)

**Products** (square, ~1000×1000px)
- `ring-1.jpg`  — Esmeralda Solitaire Ring
- `ring-2.jpg`  — Andes Halo Ring
- `ring-3.jpg`  — Verde Stacking Ring
- `ear-1.jpg`   — Rocío Emerald Studs
- `ear-2.jpg`   — Cascada Drop Earrings
- `ear-3.jpg`   — Bogotá Huggie Hoops
- `set-1.jpg`   — Esmeralda Gift Set
- `set-2.jpg`   — May Birthstone Duo

**Gallery** (mixed sizes; the layout handles it)
- `gallery-1.jpg` … `gallery-6.jpg`

## Tips
- JPG or WebP, keep each under ~400 KB for fast loading.
- Square, well-lit, plain/neutral background reads most "premium".
- You can add or rename products/prices in the `PRODUCTS` array near the top of the `<script>` in index.html.
